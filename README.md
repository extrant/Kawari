## Known Issues / 已知问题
- 疑似服务器未正确同步装备耐久度，导致排本客户端会出现部分装备耐久过低的提示。
- ~CP/GP值不跟着装备变化，而是固定为10000。~
- CP/GP值暂时未实现完整的循环机制，依赖于制作/采集系统的完善，待评估。
- 生产职业随身附带的小实体暂时未被正常处理，导致使用生产职业对魔晶石操作时对着空气播动画。
- ~排本系统简化，没有真正的任务搜索器系统。~ （预期之内）
- 无Director脚本的副本出生朝向可能为错误朝向。
- 战斗状态（如职业量谱）可能出现意料之外的跨区域继承，从而导致客户端可能出现意料之外的行为。 （简单点说就是开外挂的ACR容易出现狂暴鸿儒因等级同步而无法释放的技能）
